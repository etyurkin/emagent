#+TITLE: emagent
#+AUTHOR: Evgeniy Tyurkin
#+OPTIONS: toc:t num:nil

Emacs-native ACP chat assistant for Emacs internals, elisp, and org-mode work.

Emagent opens an org-mode scratch buffer per project, sends prompts to an external
ACP agent (Cursor or Claude).

* Requirements

- Emacs 29.1+
- An ACP agent on =PATH=:
  - *Cursor* (default): [[https://cursor.com/cli][Cursor CLI]] → =cursor-agent acp=
  - *Claude*: =npm install -g @agentclientprotocol/claude-agent-acp= and =ANTHROPIC_API_KEY=

** Shell environment

Emagent runs agent shell commands via =/bin/zsh -c= (a non-interactive shell that
does *not* source =~/.zshrc=).  Tools like =mvn=, =node=, =cargo=, etc
 must be set in =~/.zshenv= to be visible to emagent and
the agents it spawns.

Typical =~/.zshenv= additions:

#+BEGIN_SRC sh
# PATH — tools emagent shell commands will call
export PATH="$HOME/.local/bin:$HOME/bin:$PATH"
export PATH="$HOME/.npm-global/bin:$HOME/.jenv/bin:$HOME/.jenv/shims:$PATH"
#+END_SRC

Check which shell Emacs uses: =(shell-file-name)=.
=emagent-extra-exec-paths= is a separate escape hatch for binaries that need
to be on Emacs's own =exec-path= (e.g. =cursor-agent=, =claude-agent-acp=).

* Install

#+BEGIN_SRC emacs-lisp
(use-package emagent
  :ensure (:host github :repo "etyurkin/emagent" :depth 1)
  :commands (emagent emagent-cursor-start emagent-claude-start emagent-mode emagent-set-model)
  :custom (emagent-default-provider (if (equal (getenv "EMAGENT_AGENT") "claude")
                                       'claude
                                     'cursor)))
#+END_SRC

Set =EMAGENT_AGENT= to =claude= or =cursor= to pick the default provider when
Emacs starts.

For a local clone, add =:load-path "~/path/to/emagent"= instead of =:ensure=.

* Usage

| Key / command                       | Action                                           |
|-------------------------------------+--------------------------------------------------|
| =M-x emagent=                         | Start a session (infers cwd, selects agent)      |
| =M-x emagent-cursor-start=            | Start with the Cursor provider                   |
| =M-x emagent-claude-start=            | Start with the Claude ACP provider               |
| =M-x emagent-mode=                    | Reconnect a saved buffer (agent + session)       |
| =M-x emagent-set-model=               | Change ACP model mid-session                     |
| =C-c C-c=                             | Send =* user>= block; execute src block when inside one |
| =C-c p=                               | Insert a new =* user>= prompt heading             |
| =C-c a=                               | Attach current buffer summary to next prompt     |
| =C-c b=                               | Queue a follow-up ("btw") for after agent finishes |
| =C-c d=                               | Pick project files to attach to next prompt      |
| =C-c e=                               | Attach compilation/flymake errors to next prompt |
| =C-c i=                               | Attach image file (or clipboard image)           |
| =C-c m=                               | Set model                                        |
| =C-c l=                               | Show emagent log (=*Emagent Log*=)                |
| =C-c ?=                               | Command palette (transient menu)                 |
| =M-x emagent-chat-insert-last-response= | Insert last response into another buffer        |
| =M-x emagent-chat-insert-src-block=   | Pick a src block from last response and insert  |
| =TAB= on =/command= line              | Complete slash commands (skills / built-ins)     |
| =TAB= on =# --- emagent ---=           | Fold / unfold the response block                 |
| =TAB= elsewhere                       | =org-cycle= (headlines, Reasoning, etc.)          |
| =C-g C-g=                             | Interrupt agent response                         |
| =C-x k=                               | Kill buffer and disconnect agent                 |

** Project directory and agent

Each prompt is formatted as a =* username>= org heading so you can fold an
entire exchange (question + reply) with a single =TAB=.  Type after the
=* username>= stub and press =C-c C-c=; multiline prompts work without selecting
a region — the entire heading block is captured automatically.

To re-evaluate a previous prompt, edit its =* username>= heading and press
=C-c C-c= again — the old response is removed and the agent is called with the
updated text.  Use =C-c C-n= to insert a fresh heading if the stub was deleted.

=M-x emagent= infers the project directory from the current buffer's
=default-directory= (or =~/=).  Prefix argument (=C-u M-x emagent=) picks the
directory interactively.

If both =cursor-agent= and =claude-agent-acp= are installed, emagent prompts
which to use (defaulting to =emagent-default-provider=).  The chosen provider,
session, project, model, and allowed tools are saved in the buffer header as
=#+EMAGENT_*= properties.

** Saved sessions

Save the buffer to a =.org= file (=C-x C-s=).  Each buffer begins with
=# -*- mode: emagent -*-=, so Emacs activates =emagent-mode= and reconnects
automatically the next time the file is opened.  The persisted agent, session
id, model, and project directory are all restored from the =#+EMAGENT_*= header.

*Note:* the agent can only resume a session that has at least one completed
exchange.  A buffer saved before any prompt was sent will reconnect but start a
fresh session — the agent has nothing stored yet to resume.

** Response blocks

Agent responses appear between =# --- emagent ---= / =# --- /emagent ---=
delimiters.  TAB on the opening delimiter folds the entire block.

- *Reasoning* (=#+begin_quote Reasoning=) — streamed thinking text; folds
  automatically when reasoning finishes.  Tool calls made during reasoning
  appear as =→ tool-name= annotations inside the block.
- *Executing* (=#+begin_quote Executing=) — accumulates tool calls during the
  execution phase (one line per tool); folds when the agent resumes writing.

** Queued follow-ups (/btw/)

Press =C-c b= while the agent is running to queue a follow-up message.  A
minibuffer opens — type your note, press Enter.  The text is stored and sent
automatically as =btw, <your message>= when the agent finishes.  A =# [btw]=
indicator appears in the buffer and the mode line shows =⏳btw=.

** Cursor notes

Before first use, authenticate: =cursor-agent login= in your terminal.  Without
authentication, the session runs in a limited mode that rejects the Auto model.
Model IDs in the mode line are shown without technical parameters
(=claude-sonnet-4-6= not =claude-sonnet-4-6[thinking=true,...]=;
=auto= not =default[]=).

Context window percentage (=ctx%=) is only available with Claude; cursor-agent
does not expose token usage via ACP.

* Customization

| Variable                          | Default      | Description                                       |
|-----------------------------------+--------------+---------------------------------------------------|
| =emagent-default-provider=          | ='cursor=      | =cursor= or =claude=                                  |
| =emagent-cursor-acp-command=        | =("cursor-agent" "acp")= | Cursor spawn command                  |
| =emagent-claude-acp-command=        | =("claude-agent-acp")=   | Claude spawn command                  |
| =emagent-acp-file-access=           | =t=            | Route file I/O through Emacs                      |
| =emagent-acp-prefer-emacs=          | =t=            | Prefer Emacs tools over agent defaults            |
| =emagent-allowed-tools=             | =nil=          | Tools that skip confirmation                      |
| =emagent-tools-show-written-buffer= | ='magit-diff=  | Show file after write: =nil=, =t=, or ='magit-diff=   |
| =emagent-shell-block-no-verify=     | =t=            | Refuse =git --no-verify=                            |
| =emagent-shell-guard-push=          | =t=            | Block push when branch PR is already merged       |
| =emagent-shell-redirect=            | =t=            | Auto-redirect =cat=/=grep=/=git= to emagent tools     |
| =emagent-shell-suggest=             | =t=            | Suggest emagent alternative for shell commands    |
| =emagent-acp-extra-mcp-config-file= | ="~/.claude.json"= | Forward MCP servers from this file to the agent |
| =emagent-oauth-auto-browse-url=     | =nil=          | Auto-open OAuth authorize URLs in a browser       |
| =emagent-acp-watchdog-timeout=      | =300=          | Seconds of silence before aborting a stalled prompt |

Destructive tool calls (=write_file=, =delete_file=, shell commands, etc.)
prompt before running using inline buttons in the chat buffer.  =write_file=
shows a unified diff before asking.  Answer /Allow all/ to remember a tool for
the current buffer session.

** Eval safety

The =eval= MCP tool runs Emacs Lisp directly in the live Emacs process.
Dangerous symbols (=delete-file=, =shell-command=, =write-region=, =load-file=,
etc.) trigger a confirmation prompt showing the full code before execution.
=kill-emacs= and =pause-emacs= are permanently blocked.

The agent is guided to call =check_elisp= (paren validator) before =eval= for
any non-trivial form, and =elisp_guide= (built-in Elisp reference) before
writing new code.

** MCP tools exposed to the agent

| Tool            | Description                                               |
|-----------------+-----------------------------------------------------------|
| =read_file=       | Read through Emacs (includes unsaved buffer content)      |
| =write_file=      | Write via Emacs buffer (undo-able, diff shown to user)    |
| =grep=, =find_files=, =list_files= | File search within session root          |
| =git_status/diff/log= | Git info via Emacs                                    |
| =compile=         | Build/test via compilation-mode (errors navigable with =M-g n=) |
| =buffer_list=     | Open files inside the project visible to Emacs            |
| =imenu_index=     | Function/class outline for any file                       |
| =eval=            | Execute Emacs Lisp in the live process                    |
| =check_elisp=     | Validate Elisp paren balance before eval                  |
| =elisp_guide=     | On-demand Elisp reference (patterns, pitfalls, examples)  |
| =apropos=         | Find symbols by name fragment                             |
| =apropos_doc=     | Find symbols by docstring meaning                         |
| =describe_symbol= | Full docstring + signature                                |

Build commands (=mvn=, =gradle=, =cargo=, =make=, =npm test=, etc.) are always
routed through =compile= for navigable error output, regardless of other settings.

** MCP gateway forwarding

Emagent reads the =mcpServers= block from =emagent-acp-extra-mcp-config-file=
(default =~/.claude.json=) and forwards those servers to the ACP agent alongside
the built-in emagent tools.  This lets Claude-compatible agents use any MCP
gateway you have configured — no separate setup required.  Set to =nil= to
disable forwarding.
